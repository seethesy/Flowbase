# Sanitized proposal samples

These finalized Word exports are test fixtures for proposal extraction:

- `sample-proposal-event.docx` contains a multi-section event proposal with menu, rentals, decor, florals, staffing, fees, and payment terms.
- `sample-proposal-dinner.docx` contains a dinner proposal with a menu, staffing, rentals, fees, and payment terms.

Client and contact names, phone numbers, email addresses, and street addresses were replaced with placeholders. Embedded images and document author metadata were removed. The proposal headings, tables, quantities, charges, totals, and payment language remain representative of the source layouts. No original exports belong in this directory.
