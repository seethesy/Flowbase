# Closeout and returns

- **Closeout and returns (FLOW-157)**: the "Closeout and returns" hub section checks every pull-list line back in. Equipment counts must add up (returned + damaged + missing = pulled); consumables record how many were used, and the rest is leftover. Sub-rented items still out must be marked returned to their vendor (with notes). Submitting once closes the event out (`event_closeouts`, `closeout_lines`), moves it from Preparation to Finished and emits `event.completed`. A balance due does not block it: payments stay in the payment schedule.
- **Technical decision, stock movements at closeout**: pull-list status changes don't create stock movements, so stock was never taken out when an item was pulled. Closeout reconciles the ledger for what came back. For each stocked item it records a `pull` and a `return` of the returning quantity (net zero, the visible check-in), then a `damage_loss` for damaged and for missing units, which leave stock for good; consumables record a `consume` for what was used and return the leftover the same way. So returning 98 of 100 plates with 2 damaged creates a return of 98 and a damage movement of 2, and stock ends 2 lower. Items sub-rented from a vendor never held our stock and get no movements. All movements link to the event. If pulls are ever recorded in the ledger, this reconciliation must be revisited.
