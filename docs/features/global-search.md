## Global search

`GET /api/search?q=<text>` (FLOW-46, `worker/records/search.ts`, ADR-24) powers the header search (`src/features/search.tsx`). It searches client names and contact names, lead names, event titles, venue names, inventory item names, vendor names (FLOW-84) and recipe names (FLOW-217) with Postgres full-text search plus pg_trgm, so one typo still matches (trigram word similarity ≥ 0.4); emails, item codes and phone numbers (4+ digits, punctuation ignored) match any part as typed. It returns up to 20 results, at most 5 per type, best first (`{type, id, title, subtitle, path, score}`); queries under 2 characters return nothing. Every type is filtered by the caller's own visibility (the same rules as the lists: a salesperson sees only their own clients, leads and events, staff only the events they work), client contact email and phone and vendor contacts are matched only for FT+ users; lead email and phone match for anyone with access to the lead, and archived records are left out. Migration `0013` enables `pg_trgm` (`CREATE EXTENSION IF NOT EXISTS`, available on Supabase Free) and adds trigram indexes. Recipes (FLOW-217) are matched by dish name for everyone with `recipes.read`, active and unarchived ones only, with their category as the subtitle and no cost fields; migration `0029` adds their trigram index.
